# Security policy

RailWeave processes untrusted add-on trees and can invoke an external adapter only when the user explicitly supplies `--adapter`.

Please do not disclose a suspected path traversal, unsafe file copy, resource-exhaustion or command-execution vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository. Include the affected version, minimal reproduction and expected impact.

The current supported line is the latest tagged release. Security fixes are not guaranteed for older releases.

RailWeave does not attempt to decrypt protected game content or bypass DRM. Reports asking for circumvention are out of scope.
